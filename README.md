# Clasoom Android App — v1.0.0

This is the first Android wrapper app for the existing Clasoom website.

## Included
- Student / Teacher / Admin login through the existing Clasoom website.
- Existing Supabase authentication and role-based dashboards remain unchanged.
- Android back button support.
- Pull-to-refresh.
- Web file picker support for teacher/admin uploads where the website requests a file.
- Persistent WebView cookies and local storage for login sessions.
- Clasoom branding and portrait orientation.

## Website
https://clasoom.wasmer.app/

## Build
Open this folder in Android Studio. Allow Gradle to download the Android Gradle Plugin and AndroidX dependencies, then Build > Build APK(s).
